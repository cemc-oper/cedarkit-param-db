# cedarkit-param-db

This repository previously maintained the CedarKit element registry. The registry, authoring tables, review tools, and exporter were retired from the active CEMC GRIB2 read path. The original source is available at revision `e0aba5374e00ce88656760f05d6bd2c1ba79dca2` and in the CedarKit workspace stage 1.1 archive.

Use reki with native GRIB keys to locate and decode original messages. The separately published parameter browser snapshot remains a historical export.
